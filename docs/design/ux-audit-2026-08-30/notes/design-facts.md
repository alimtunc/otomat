## Architecture notes for audit
- packages/ui = single design system: primitives (shadcn-style: button/badge/input/select/dialog/dropdown/popover/tabs/switch/checkbox/textarea/tooltip/command/combobox/collapsible/scroll-area/resizable/skeleton) + components (status-chip via central STATUS_REGISTRY, chip, kbd, segmented, pill-tabs, empty/error-state, meta-list, timeline-event-row, topbar, app-shell/sidebar, project-switcher, command-palette, toaster, offline-banner, reconnecting-bar, connection-status-indicator).
- Central status registry = strength. tone.ts maps tones→classes.
- RouteShell used by all views. Right rail = SidePanel resizable + collapsible w/ toggle.
- Tables via TanStack Table + shared TABLE classes; grouped via rowSlices.
- Issues list/board separate components; issue detail = workspace with rail sections (many small section files).
- Diff: review-workbench with own css file (review-diff.css) — the one screen with bespoke CSS.
- Settings pages each = SectionHeading + cards; forms with primary save buttons per card.
- Known route set: issues, issues/$id, runs, runs/$id(+report/logs/diff/pr), pull-requests/$id/diff, reviews, inbox, usage, settings/*, agents, skills.
- Density: compact default; comfortable option. Theme: dark default, light exists. Direction identities brass/viridian in tokens.
